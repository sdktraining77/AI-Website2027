# Web Development Course

## Course Name
Full-Stack Web Development Fundamentals

## Description
This course teaches students how to build interactive websites. Learners start with HTML and CSS, then study JavaScript and basic front-end development. They are introduced to server-side concepts and learn how a website communicates with a database. The course ends with a small website project.

## Duration
10 weeks (60 training hours).

## Prerequisites
- Basic computer and internet skills.
- No previous programming experience is required.

## Target Audience
- Beginners interested in building websites.
- University students who want practical web development skills.
- People preparing to pursue a career in front-end or full-stack development.

## Learning Outcomes
By the end of the course, students will be able to:
- Create web pages using HTML.
- Style pages using CSS.
- Add interactivity using JavaScript.
- Understand basic server and database concepts.
- Build and present a simple website.
