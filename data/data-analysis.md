# Data Analysis Course

## Course Name
Data Analysis with Python and Power BI

## Description
This course teaches learners how to turn raw data into useful insights. Students learn data collection basics, data cleaning, exploratory data analysis, and visualization. They use Python with Pandas for data preparation and Power BI to create interactive dashboards. The final activity is a small data analysis project.

## Duration
6 weeks (36 training hours).

## Prerequisites
- Basic computer skills.
- Basic spreadsheet knowledge is recommended.
- No previous Python experience is required.

## Target Audience
- University students interested in data.
- Beginners who want to learn data analysis.
- Professionals who work with reports and business data.

## Learning Outcomes
By the end of the course, students will be able to:
- Identify common data quality issues.
- Clean and organize datasets.
- Perform basic exploratory data analysis.
- Create charts and dashboards.
- Communicate findings using data.
